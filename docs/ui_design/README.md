# UI Design - Milestone 3

## Overview

I created wireframes and mockups for the Task Manager GUI using Figma. The goal was to make the application simple and easy to use while keeping the existing features.

## Screens

I designed five main screens:

1. **Main Task List** - View tasks, mark tasks as completed, edit, delete, and filter tasks.
2. **Add Task** - Add a new task with input validation.
3. **Edit Task** - Update an existing task.
4. **Delete Confirmation** - Confirm before deleting a task.
5. **Empty State** - Display a message when there are no tasks.

## Design Decisions

I used a simple layout with blue and white colors to keep the interface clean and consistent.

- Buttons and input fields are placed consistently.
- Completed tasks are shown with strikethrough text.
- Error messages appear when required fields are empty.
- A confirmation message prevents accidental deletion.
