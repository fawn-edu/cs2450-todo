# Task Manager GUI Design – Milestone 3

This folder contains the updated GUI wireframes and mockups for the Task Manager application.

## Screens
- Main task list
- Empty state
- Add task
- Edit task
- Delete confirmation

Each screen includes a wireframe and a high-fidelity mockup (10 images total).

## Design decisions
- All, Active, and Completed tabs help users filter tasks.
- Task priority is optional (A–Z, with A highest and no priority lowest).
- Tasks are shown in priority order.
- Add and Edit screens include a priority dropdown.
- Delete confirmation helps prevent accidental deletion.
- The empty state guides users to create their first task.

## Team feedback
Updated the designs to include priority labels and selectors and to remove the redundant total/completed summary.
